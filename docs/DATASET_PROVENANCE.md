# Dataset provenance and redistribution status

This document records the provenance audit for the public-data fixtures used by
the three Python ports, and the redistribution decision taken for each source.
It closes the readiness finding "dataset provenance/redistribution terms
unverified" by replacing an undocumented assumption with recorded, machine-
checked metadata and an explicit clearance status.

**Audit date:** 2026-10-20
**Environment:** R 4.6.1, x86-64 Linux. Package versions and license strings were
read from the installed `DESCRIPTION` files (`packageDescription()`); dataset
dimensions and zero fractions were measured from the loaded objects.

## Status summary

| Source | Used by | Redistribution cleared? | Disposition |
|---|---|---|---|
| QMP (`SPRING::QMP`) | CCLasso, SPIEC-EASI, SPRING fixtures | **No** | Test artifact only; do not publish or ship the matrix until cleared |
| American Gut Project Round 1 (`SpiecEasi::amgut1.filt`) | CCLasso fixtures | **No** | Test artifact only; do not publish or ship the derived matrices until cleared |
| GlobalPatterns (`phyloseq::GlobalPatterns`) | CCLasso, SPIEC-EASI, SPRING fixtures | **No** | Test artifact only; do not publish or ship the derived matrices until cleared |
| Deterministic synthetic data | CCLasso fixtures | Yes (n/a) | Generated by `tests/r_reference/generate_golden.R`; no third-party rights |

"Not cleared" is a deliberate, recorded status, not an unresolved unknown: the
fixtures remain in the repository so the equivalence suites run in CI, but they
are **not** part of a distributable or citable data payload. Every public-data
`params.json` carries `"redistribution_cleared": false`, and the equivalence
tests assert the field exists and is a boolean.

## Recorded provenance

### QMP (Quantitative Microbiome Project)

- **Object:** `QMP`, 106 samples × 91 taxa, 27.10% zero entries.
- **Package:** SPRING 0.99.0, `License: GPL-3`.
- **Citation:** Vandeputte et al. (2017) *Nature* 551:507–511,
  doi:10.1038/nature24460; Yoon, Gaynanova and Müller (2019) *Front Genet*
  10:516, doi:10.3389/fgene.2019.00516.
- **Local pin:** `cclasso-python/tests/r_reference/data/QMP.rda`,
  SHA-256 `603ddba2ca665f57aabf963594e80a152d2fc8c85bbd614ac8b828b3a9ff1e8b`.
  Vendored so fixture regeneration no longer depends on the untracked
  `SPRING-master/` tree. `QMP_RDA` still overrides the path.
- **Redistribution:** The SPRING package license covers the code; the data are
  a curated subset of a published study. No standalone data-use grant is
  recorded in the package. Status: **not cleared**.

### American Gut Project Round 1 (`amgut1.filt`)

- **Object:** `amgut1.filt`, 289 samples × 127 taxa, 30.64% zero entries.
- **Package:** SpiecEasi 1.99.0, `License: GPL (>= 3)`.
- **Documented source:** `?AGP` in SpiecEasi points to
  `http://humanfoodproject.com/americangut/`. That URL was not reachable during
  the audit, and the package metadata records no separate data-use licence.
- **Human-derived data:** The matrix is human microbiome data; participant-level
  metadata is not redistributed, and the fixture IDs are anonymised, but the OTU
  counts derive from human samples.
- **Redistribution:** **not cleared**. Do not commit the raw matrix or derived
  fixtures to a public release, and do not ship them in the Electron bundle
  until the American Gut Project data-use terms are confirmed in writing.

### GlobalPatterns (`phyloseq::GlobalPatterns`)

- **Object:** `GlobalPatterns`, 26 samples × 19,216 taxa, 79.07% zero entries.
- **Package:** phyloseq 1.56.0, `License: AGPL-3`.
- **Citation:** Caporaso et al. (2011) *PNAS* 108(Suppl 1):4516–4522,
  PMCID PMC3063599, doi:10.1073/pnas.1000080107. The *Rd* page records that
  J. Gregory Caporaso supplied the OTU-clustered files for inclusion in the
  package.
- **Our derived fixtures:** only the OTU table is used; sample metadata and the
  phylogenetic tree are dropped. Core cases select the most prevalent varying
  taxa (0% zeros); the prevalence-spread variant is a retained failure input.
- **Redistribution:** **not cleared**. The AGPL-3 package licence does not by
  itself establish a redistribution right for the underlying study data.

## What this changes

1. `scripts/public_microbiome_cases.R` stamps each public case with
   `source_package`, `source_package_version`, `source_license`,
   `source_citation`, `retrieval_date` and `redistribution_cleared`.
2. `generate_golden.R` writes those fields into every public `params.json`, and
   also records QMP provenance for the two QMP cases.
3. `tests/test_equivalence.py::test_public_fixtures_record_provenance` fails if a
   public fixture loses or blanks a provenance field, or if the clearance flag is
   missing.
4. `docs/STATISTICAL_RELEASE_READINESS.md` now states the clearance status
   instead of leaving it unverified.

## Required action before publishing data

Choose **one**:

- obtain written permission from the rights holders and set
  `redistribution_cleared = true` with the permission reference recorded here; or
- replace the public-data fixture families with synthetic or locally regenerated
  data, leaving the public matrices in a developer-only, non-published tree; or
- keep the app and fixtures internal-only and cite the original studies without
  redistributing their matrices.

Regeneration remains possible without redistribution because the code and the
deterministic preprocessing are committed; only the derived numeric fixtures
are restricted.
