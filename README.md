# Microbiome Co-occurrence Network Analysis

Desktop application for microbial co-occurrence network analysis from abundance tables (bacteria, fungi, or both), designed for users who want a graphical workflow instead of writing code.

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Electron](https://img.shields.io/badge/Electron-44-47848F.svg)](https://www.electronjs.org/)
[![Python](https://img.shields.io/badge/Python-3.9%2B-3776AB.svg)](https://www.python.org/)

## What you can do in the app

- Compute taxa correlations with Spearman or SparCC.
- Build condition-specific co-occurrence networks.
- Analyze bacteria-only, fungi-only, or cross-domain bacteria-fungi relations.
- Explore network results interactively.
- Run local seed-based community detection.
- Export results as CSV and JSON.
- Reopen and compare previous analyses from History.

## Typical workflow inside the app

1. Create a new analysis.
2. Upload abundance tables and metadata.
3. Select analysis parameters.
4. Run the analysis and monitor progress.
5. Review tables, summaries, graphs, and clustering output.
6. Save, reopen, or compare runs from History.

## Input files

### Abundance tables

- Format: CSV or TSV.
- Content: samples and taxa abundance values.

### Metadata

- Format: CSV or TSV.
- Must include the column Combination_treat2.
- At least two distinct values in Combination_treat2 are required for condition comparison.

## Output generated by the app

- Full analysis result object in JSON.
- Significant pair tables in CSV.
- Local clustering snapshot with metadata.
- Persistent run archive available through History.

## Current limitations

- FastSpar is not bundled for macOS and Linux arm64.
- Multiple-testing correction is not applied automatically.
- Export formats are CSV and JSON only.

## Privacy

The app runs locally. Analysis data is not sent to cloud services.

## Quick troubleshooting

- Python not found: install Python 3 and select the interpreter in Settings if needed.
- Missing Python packages: allow the app to complete first-run dependency setup.
- SparCC unavailable: switch to Spearman or configure a valid FastSpar path.
- Metadata rejected: verify the Combination_treat2 column exists.
- Empty or sparse network: relax p-value threshold or check sample counts per condition.

### Stack

- Electron 44

- Python 3 backend
- NetworkX, SciPy, NumPy

```text

|- src/
|  |- main/
|  |- renderer/
|  `- shared/

|  |- analysis.py

|  `- clustering/

```

### Local development setup

```bash
npm install
python3 -m pip install -r python/requirements.txt
npm run dev
```

### Useful scripts

```bash
npm run dev
npm start
npm run build
npm run test
npm run lint
```

### Important packaging constraint

- Python runtime files are shipped via extraResources.
- Python scripts must stay outside app.asar.
- Build output is written to release.
